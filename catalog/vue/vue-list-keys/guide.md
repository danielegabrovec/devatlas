## Obiettivo
Usare ID del dominio per preservare l'identità delle righe durante le rimozioni.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
La riga selezionata scompare e le altre conservano il proprio ID.

## Integrazione
Usare ID del dominio per preservare l'identità delle righe durante le rimozioni. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
