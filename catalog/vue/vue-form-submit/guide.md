## Obiettivo
Usare submit.prevent e messaggi visibili invece di una navigazione della pagina.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
L'invio segnala indirizzo valido o errore, senza ricaricare.

## Integrazione
Usare submit.prevent e messaggi visibili invece di una navigazione della pagina. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
