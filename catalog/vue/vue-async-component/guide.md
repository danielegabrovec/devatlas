## Obiettivo
Usare defineAsyncComponent per creare un chunk separato gestito da Vite.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il componente dettagli viene richiesto al primo utilizzo.

## Integrazione
Usare defineAsyncComponent per creare un chunk separato gestito da Vite. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
