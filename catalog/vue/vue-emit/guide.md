## Obiettivo
Usare defineEmits invece di modificare una prop del componente padre.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il clic del figlio aggiorna il messaggio del padre.

## Integrazione
Usare defineEmits invece di modificare una prop del componente padre. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
