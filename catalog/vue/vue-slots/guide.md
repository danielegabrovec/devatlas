## Obiettivo
Lasciare al padre intestazione e corpo mantenendo un layout comune.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
La scheda ospita titolo e corpo forniti dal padre.

Lasciare al padre intestazione e corpo mantenendo un layout comune. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
