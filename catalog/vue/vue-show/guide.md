## Obiettivo
Nascondere un editor conservandone il contenuto e lo stato DOM.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Dopo aver scritto, nascondere e riaprire conserva il testo.

## Integrazione
Nascondere un editor conservandone il contenuto e lo stato DOM. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
