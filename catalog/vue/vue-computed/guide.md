## Obiettivo
Ricalcolare il prezzo derivato senza memorizzare un secondo stato da sincronizzare.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.vue; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Cambiare la quantità modifica immediatamente il totale.

## Integrazione
Ricalcolare il prezzo derivato senza memorizzare un secondo stato da sincronizzare. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
