## Progetto
Salva tutti i file nella stessa cartella. Il pulsante aggiunge la nota soltanto dopo il successo della scrittura. Il caricamento valida l'elenco JSON; un errore viene mostrato senza interrompere l'interfaccia. Il file temporaneo viene sostituito nella stessa cartella per ridurre il rischio di salvataggi parziali.

## Prova manuale
Aggiungi due note, chiudi e riapri. Le note devono ricomparire. Prova una stringa vuota: non deve essere aggiunta.
