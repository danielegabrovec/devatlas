## Obiettivo
Usare inject per accedere a una istanza condivisa con stato signal.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/app.ts; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il servizio conserva lo stato al di fuori della classe del componente.

## Integrazione
Usare inject per accedere a una istanza condivisa con stato signal. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
