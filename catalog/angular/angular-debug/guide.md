## Sessione
Apri la cartella in VS Code e avvia il server locale sul porto 4200. Se il tool sceglie un'altra porta, modifica url in launch.json. Avvia Debug browser locale con Edge disponibile.

## Breakpoint
Apri src/app.ts, metti il breakpoint nell'handler del clic o usa gli strumenti del browser per fermarti sugli eventi click. Premi il pulsante e osserva lo stato. Il debugger non avvia da solo il server; interrompi entrambi al termine.
