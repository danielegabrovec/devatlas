## Obiettivo
Associare due comandi a tasti del campo senza listener globali.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/app.ts; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Invio salva l'anteprima, Escape pulisce il campo.

## Integrazione
Associare due comandi a tasti del campo senza listener globali. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
