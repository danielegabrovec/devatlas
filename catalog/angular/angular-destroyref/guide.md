## Obiettivo
Registrare la pulizia del lavoro periodico sul ciclo di vita del componente.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/app.ts; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il timer viene rilasciato alla distruzione del componente.

Registrare la pulizia del lavoro periodico sul ciclo di vita del componente. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
