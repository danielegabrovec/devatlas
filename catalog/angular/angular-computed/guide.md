## Obiettivo
Derivare un valore da un segnale senza mutare due proprietà a ogni evento.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/app.ts; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il totale segue la quantità.

## Integrazione
Derivare un valore da un segnale senza mutare due proprietà a ogni evento. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
