## Obiettivo
Usare date e number per presentazione senza trasformare i dati originali.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/app.ts; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Sono mostrati data UTC e numero con due decimali.
