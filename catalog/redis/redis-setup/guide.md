## Piattaforma
Installa Redis Open Source8.2 e redis-cli in Linux o WSL. La ricetta usa un processo a sé su127.0.0.1:6381 e dati in .redis-data; non richiede Docker Desktop né un pacchetto Windows nativo non ufficiale.

## Avvio
Lascia il server nel primo terminale e usa il secondo per il controllo. PING deve rispondere PONG. Il prefisso atlas_demo distingue le chiavi del laboratorio. Il catalogo non esegue automaticamente questi comandi.
