## Obiettivo
Usare DisplayAlertAsync nell'handler di un pulsante.

## Collocazione
Salva tutti i file esportati mantenendo i percorsi indicati. Il file .csproj è nella cartella di lavoro dei comandi; non incollare il contenuto in un diverso progetto che abbia già una classe App o MainWindow omonima. L'esempio costruisce la UI in C#, senza richiedere file XAML aggiuntivi oltre a quelli forniti.

## Prova
Avvia e usa il controllo descritto: mostrare un messaggio asincrono. Il codice specifico della ricetta è nel costruttore della pagina/finestra.

## Compatibilità
Windows 10 build 19041+; .NET 10 SDK con workload MAUI Windows installato; Visual Studio 2026 con MAUI. Non occorrono Android o un Mac per questo esempio Windows. Esecuzione non attestata: Android, iOS e macOS non vengono simulati né dichiarati verificati.
