## Obiettivo
Esporre una scelta ON/OFF nella cache CMake.

## Avvio
Salva main.cpp, CMakeLists.txt e gli eventuali file aggiuntivi rispettando le directory. Esegui i comandi dalla cartella sorgente; build è separata dai sorgenti. Il risultato è il target recipe, mentre la proprietà specifica è dichiarata soltanto sul target interessato.

## Controllo
Leggi il log di configurazione e build. CMake interrompe configure se il compilatore richiesto non è disponibile. I comandi Windows sono esempi PowerShell; configurazioni su Linux e macOS non sono dichiarate eseguite.

## Dettaglio
Esporre una scelta ON/OFF nella cache CMake.
