## Scopo
Registrare la pulizia prima di utilizzare il file temporaneo.

## Esecuzione
Salva example.sh in una cartella nuova ed esegui il comando da quella stessa cartella. 

## Lettura del risultato
Registrare la pulizia prima di utilizzare il file temporaneo. Il codice è fornito per intero: leggi gli argomenti e i percorsi prima dell'esecuzione. Gli esempi che scrivono dati creano file temporanei o operano soltanto nel repository dimostrativo indicato.

## Compatibilità
Linux o distribuzione Linux in WSL, Bash 5 e strumenti GNU. Gli script non sono dichiarati verificati su macOS.
