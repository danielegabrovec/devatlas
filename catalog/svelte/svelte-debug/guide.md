## Sessione
Apri la cartella in VS Code e avvia il server locale sul porto 5173. Se il tool sceglie un'altra porta, modifica url in launch.json. Avvia Debug browser locale con Edge disponibile.

Apri src/App.svelte, metti il breakpoint nell'handler del clic o usa gli strumenti del browser per fermarti sugli eventi click. Premi il pulsante e osserva lo stato. Il debugger non avvia da solo il server; interrompi entrambi al termine.
