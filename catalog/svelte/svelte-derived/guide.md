## Obiettivo
Usare $derived per ricalcolare il prezzo partendo dalla quantità.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.svelte; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il prezzo segue la quantità senza una seconda assegnazione manuale.

## Integrazione
Usare $derived per ricalcolare il prezzo partendo dalla quantità. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
