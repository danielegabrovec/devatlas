## Obiettivo
Dichiarare un blocco parametrico e renderizzarlo con dati differenti.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.svelte; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Lo snippet produce una scheda con dati passati come argomento.

## Integrazione
Dichiarare un blocco parametrico e renderizzarlo con dati differenti. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
