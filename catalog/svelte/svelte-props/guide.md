## Obiettivo
Destrutturare una prop con valore predefinito nel componente Svelte5.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.svelte; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il figlio visualizza il nome del padre.

## Integrazione
Destrutturare una prop con valore predefinito nel componente Svelte5. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
