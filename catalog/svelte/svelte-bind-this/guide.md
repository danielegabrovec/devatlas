## Obiettivo
Conservare il nodo e usarlo soltanto dopo onMount.

## File e avvio
Esporta i file conservando src e le eventuali risorse public. Installa le dipendenze dalla cartella package.json e avvia il server sul loopback. La parte specifica è nel componente src/App.svelte; i file aggiuntivi espongono il contratto del figlio o i dati richiesti.

## Risultato da controllare
Il campo riceve il cursore dopo il mount.

## Integrazione
Conservare il nodo e usarlo soltanto dopo onMount. Il dataset dimostrativo è locale; la ricetta non richiede credenziali o un backend esterno.
