## Obiettivo
Usare WrapPanel quando cambia la larghezza disponibile.

## Collocazione
Salva tutti i file esportati mantenendo i percorsi indicati. Il file .csproj è nella cartella di lavoro dei comandi; non incollare il contenuto in un diverso progetto che abbia già una classe App o MainWindow omonima. L'esempio costruisce la UI in C#, senza richiedere file XAML aggiuntivi oltre a quelli forniti.

## Prova
Avvia e usa il controllo descritto: disporre pulsanti su più righe. Il codice specifico della ricetta è nel costruttore della pagina/finestra.

## Compatibilità
.NET 8 SDK e runtime desktop del proprio sistema; nessun template richiesto. Esecuzione non attestata: Android, iOS e macOS non vengono simulati né dichiarati verificati.
