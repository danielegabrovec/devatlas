## Obiettivo
Usare GroupName per isolare il gruppo.

## Collocazione
Salva tutti i file esportati mantenendo i percorsi indicati. Il file .csproj è nella cartella di lavoro dei comandi; non incollare il contenuto in un diverso progetto che abbia già una classe App o MainWindow omonima. L'esempio costruisce la UI in C#, senza richiedere file XAML aggiuntivi oltre a quelli forniti.

## Prova
Avvia e usa il controllo descritto: creare scelte radio esclusive. Il codice specifico della ricetta è nel costruttore della pagina/finestra.

## Compatibilità
Windows 10 build 19041+; .NET 8 SDK, Windows SDK e workload WinUI in Visual Studio. Questa è una baseline compatibile Windows App SDK 1.8.12, non la versione più recente. Esecuzione non attestata: Android, iOS e macOS non vengono simulati né dichiarati verificati.
