## Obiettivo
Prelevare un solo lavoro senza assegnarlo contemporaneamente a due worker.

## Procedura
Esporta tutti i file in una cartella dedicata. Usa esclusivamente un database didattico vuoto: lo schema contiene dati sintetici. Il README specifica ordine, controlli e risultato. Esegui i comandi dalla cartella esportata.

## Verifica
Confronta i risultati con le query di controllo incluse; nessun server remoto è necessario per le varianti SQLite.
