# Catalogo libri Java

Richiede JDK17+, nessun Maven né pacchetto esterno. `javac -encoding UTF-8 --release 17 Main.java Inventory.java InventoryTest.java`, `java InventoryTest`, `java Main`. I dati sono in memoria e non vengono conservati tra gli avvii. L'ID è un codice sintetico: non valida la struttura degli ISBN reali. snapshot restituisce una copia non modificabile; i titoli sono String immutabili.
