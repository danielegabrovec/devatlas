## Scopo
Evitare che oggetti annidati vengano trasformati in stringhe.

## Esecuzione
Salva example.ps1 in una cartella nuova ed esegui il comando da quella stessa cartella. 

## Lettura del risultato
Evitare che oggetti annidati vengano trasformati in stringhe. Il codice è fornito per intero: leggi gli argomenti e i percorsi prima dell'esecuzione. Gli esempi che scrivono dati creano file temporanei o operano soltanto nel repository dimostrativo indicato.

## Compatibilità
PowerShell 7.4 o successivo (pwsh), non Windows PowerShell 5.1.
