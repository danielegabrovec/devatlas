## Scopo
Usare Get-Command ErrorAction SilentlyContinue per una dipendenza opzionale.

## Esecuzione
Salva example.ps1 in una cartella nuova ed esegui il comando da quella stessa cartella. 

## Lettura del risultato
Usare Get-Command ErrorAction SilentlyContinue per una dipendenza opzionale. Il codice è fornito per intero: leggi gli argomenti e i percorsi prima dell'esecuzione. Gli esempi che scrivono dati creano file temporanei o operano soltanto nel repository dimostrativo indicato.

## Compatibilità
PowerShell 7.4 o successivo (pwsh), non Windows PowerShell 5.1.
