## Operazione
Usare addToSet quando il significato è un insieme.

## Dataset e reset
demo.js sceglie il proprio database atlas_demo_array_set, elimina la sola collezione items e inserisce tre prodotti sintetici. Gli oggetti aggiuntivi, quando previsti, sono nominati nello stesso database. Usa soltanto il processo di laboratorio.

## Controllo
usb compare una sola volta e portable viene aggiunto.

## Compatibilità
Esempio MongoDB8.0 tramite mongosh; non è SQL e non va eseguito nel client MySQL. La validazione JavaScript non attesta l'esecuzione sul server.
